## 🔧 System-Setup

### Installierte Obsidian-Plugins (empfohlen)
- **Map View** — Kartendarstellung für GPX-Dateien
- **Daily Notes** — Tägliche Notizen
- Weitere Community Plugins nach Bedarf

### Vault-Struktur
```
Touren-Vault/
├── Wanderungen/           ← Alle Wandertouren
├── Stadtrundgänge/        ← Alle Stadtrundgänge
├── Regionen/              ← Regionale Informationen
├── Planung/               ← Reisepläne
├── Erfahrungen/           ← Reiseberichte
├── Ressourcen/            ← Diese Ordner (Docs + Templates)
├── Attachments/           ← Bilder, Karten, Medien
├── YYYY-MM-DD.md          ← Tagesnotizen
└── CLAUDE.md              ← Anleitung für Claude Code
```

## ✅ Nächste Schritte

### Für Anfänger
1. Lese **[[GPX-Setup-Anleitung]]** (Schritt 1: Map View installieren)
2. Durchsuche **[[GPX-Verwaltung]]** nach interessanten Touren
3. Lade eine GPX-Datei herunter und teste sie

### Für neue Touren
1. Kopiere **[[Tour-Template]]**
2. Speichere als `Wanderungen/[Region]/[Tourname].md`
3. Fülle mit Inhalten aus
4. GPX-Datei in `Wanderungen/[Region]/GPX/` speichern
5. Füge Link zu **[[GPX-Verwaltung]]** hinzu

### Für Vault-Verwaltung
- Nutze [[CLAUDE.md]] als Referenz für Vault-Konventionen
- Halten Sie [[GPX-Verwaltung]] aktuell, wenn neue Touren hinzufügen
